📱 Nexi – Chat & Calls App

Nexi is a modern Flutter application that combines real-time chat with video & audio calling in one simple, beautiful interface.

✨ Features

💬 1-to-1 Chat Messaging – powered by flutter_chat_ui with modern themes.

👥 Group Chats – create or join groups to chat with multiple people in real-time.

🔔 Push Notifications – Firebase Cloud Messaging (FCM) integration for real-time alerts.

📹 Video & Audio Calls – free and open-source via Zego Cloud.

👤 User Profiles – manage personal info and keep your account up to date.

🔑 Authentication – secure login & signup with Firebase.

⚡ State Management – clean architecture using Cubit + MVVM.

🛠️ Tech Stack

Flutter (Dart)

Firebase (Auth, Firestore, Cloud Messaging)

Zego Cloud (Video & Audio Calls)

flutter_chat_ui (Chat interface)

Bloc / Cubit (State management)
